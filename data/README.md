# Data folder

This folder is intentionally empty in the public repository.
Place your private files here locally (they are git-ignored):

| File | Purpose |
|------|---------|
| `OPD dataset.xlsx` | Monthly OPD performance data per doctor and branch |
| `Knowledge base.xlsx` | KPI knowledge base (6 sheets, see the main README) |

`pending_requests.json` is generated automatically at runtime.
